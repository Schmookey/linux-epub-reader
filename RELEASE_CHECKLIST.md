# Release checklist

- [x] Application identity and paths use Linux EPUB Reader.
- [x] Chapter text flows continuously in reading order.
- [x] Progress bar reports 0–100% within the active chapter.
- [x] The contents is a fixed left-hand column, with the reading page in a separate right-hand column.
- [x] Sidebar width is based on the longest chapter/page label and adapts to available window width.
- [x] Mint-green close/open buttons are placed on the sidebar edge and reading-area edge.
- [x] Unit tests cover chapter progress, sidebar sizing, DRM notices, synthetic EPUB parsing and Resume last book state migration.
- [ ] Verify Resume last book, missing-file recovery and saved position on a real Linux Mint desktop.
- [ ] Test installation and upgrades on a real Linux Mint desktop.
- [ ] Test with a broad selection of non-DRM EPUB files.
- [ ] Verify saved positions/bookmarks on the user's machine after upgrade.
- [ ] Adobe DRM remains unimplemented in-app until a licensed compatible engine is available.
- [ ] Review the selected CC BY-NC-SA 4.0 licence for software-distribution suitability.
