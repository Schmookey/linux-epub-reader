# Support

For reproducible problems, open a GitHub issue and use the bug report template. Include Linux distribution/version, Linux EPUB Reader version, reproduction steps and relevant error text.

Do not attach copyrighted books, personal reading-state files, Adobe account information, `.acsm` files, DRM licence files or private keys. Use a small synthetic EPUB if a test file is needed.

This is an early-stage project. The reader focuses on text-oriented EPUB content and does not currently embed Adobe's licensed DRM engine.
