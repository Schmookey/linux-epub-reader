# Linux EPUB Reader v0.14.0

The first release with **EBook, Audiobook and Music in one offline-first Linux desktop application**. It adds a dedicated DRM-free music player alongside EPUB reading and M4B audiobook listening.

## What's new

- **Music player:** open songs or whole local folders; browse albums and create local playlists. MP3, FLAC, WAV, Ogg/Opus, M4A/AAC/ALAC and additional MPV-supported formats are eligible. Unsupported or protected media and network URLs are rejected. M4B remains exclusive to Audiobooks.
- **Your library dashboard:** Home now shows independent Last Read, Last Listened and Last Played cards, with locally embedded artwork, author/artist, album, descriptive metadata where supplied and saved reading or playback positions.
- **Everyday music controls:** play, pause, stop, previous and next, seek, volume and mute. Music continues while you visit Home or EBook or minimise the window; returning to Music no longer reloads an active song.
- **Linux desktop media controls:** a local MPRIS2 service integrates with media keys and compatible lock screens. Preview and Stable use separate D-Bus service identities; lock-screen controls were successfully tested with Linux Mint Cinnamon.
- **Removable media:** the Flatpaks can read local drives mounted under `/media`, `/run/media` and `/mnt`, without gaining permission to modify music files on those drives.
- **Bundled Python fix:** the standalone Flatpaks include the locally patched `dbus-next` compatibility import needed for Python 3.15, with a packaging test that verifies real MPRIS registration.
- **Offline and private:** EPUB, M4B and Music libraries keep separate, local position histories and playlists. No account, streaming, network access, DRM bypass or online metadata service is used.

## Download the installers

- `linux-epub-reader_0.14.0-1_all.deb` — Debian package for Linux Mint and other compatible distributions.
- `linux-epub-reader-0.14.0.flatpak` — Stable standalone Flatpak.
- `linux-epub-reader-preview-0.14.0.flatpak` — independent Preview Flatpak with separate reading/listening history.
- `SHA256SUMS` — checksums for the three installers.

On Linux Mint, install the Debian package with `sudo apt install ./linux-epub-reader_0.14.0-1_all.deb`, or install the downloaded Stable Flatpak with `flatpak install --user ./linux-epub-reader-0.14.0.flatpak`. The Preview Flatpak uses the analogous filename. The standalone Flatpaks may need their Freedesktop runtime installed the first time, but the application itself has no network permission.

To check downloaded packages, run `sha256sum -c SHA256SUMS` from their download directory.

## Compatibility and limitations

EPUB rendering remains text-oriented, and complex fixed layouts, illustrations and rich publisher CSS may not render accurately. Protected books and audio, ACSM fulfilment and online music streaming are not supported. Some uncommon audio formats depend on the codecs provided by the chosen package. Linux desktop lock-screen controls depend on the desktop's MPRIS support and settings.

## Validation

Python 3.12 and 3.15 automated tests, Debian package checks and both Flatpak build/integration checks are required to pass for publication. The new Music player, removable-drive access, Home metadata, background playback and Cinnamon lock-screen controls were tested on Linux Mint. Release preparation and publishing are gated: a merge to main starts the draft-first publishing workflow, checks that each Flatpak was built from the release commit, refuses overwriting existing assets, and checks the SHA-256 digests of all three installers before making the release public.
