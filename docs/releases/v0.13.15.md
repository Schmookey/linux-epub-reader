# Linux EPUB Reader v0.13.15

This release brings **EPUB reading and M4B audiobook listening into one offline-first desktop app**, with a new Home dashboard and independent resume history.

## What's new

- **Home, Ebook and Audiobook navigation.** The Home dashboard shows the last-read EPUB and last-listened M4B side by side, with locally extracted cover artwork, title, author or artist, descriptions and saved progress where available.
- **Resume where you left off.** Both formats retain their positions after closing and reopening. The EPUB reader preserves its bookmarks and contents navigation; the audiobook resumes from its saved timestamp.
- **A redesigned audiobook player.** Play, pause, stop, 30-second skips, seek, volume, mute and playback speed, with clickable chapter markers on the playback timeline instead of an audiobook contents sidebar. Playback does not start automatically.
- **Responsive playback.** A dedicated MPV worker handles loading, transport controls and status updates without blocking the interface.
- **Safer local history.** Saved-state writes are atomic; if progress cannot be written, a warning is displayed instead of failing silently.
- **Independent Preview install.** The Preview Flatpak has its own application identity and state directory, `~/.local/share/linux-epub-reader-preview/`, separate from the stable application's `~/.local/share/linux-epub-reader/`. The incorrect hard-coded Preview home path has been fixed.

## Downloads

- `linux-epub-reader_0.13.15-1_all.deb` — Debian package for Linux Mint and Debian/Ubuntu-compatible distributions.
- `linux-epub-reader-0.13.15.flatpak` — standalone **stable** Flatpak bundle.
- `linux-epub-reader-preview-0.13.15.flatpak` — separate **Preview** Flatpak bundle, for testing alongside stable.
- `SHA256SUMS` — file checksums for integrity verification.

On Linux Mint, install the downloaded Debian file with the Software Manager or `sudo apt install ./linux-epub-reader_0.13.15-1_all.deb`. Install a downloaded Flatpak with `flatpak install --user ./linux-epub-reader-0.13.15.flatpak` (or use the preview file name). Flatpak may prompt to install its required runtime.

## Compatibility and privacy

Books and audiobooks must be local, DRM-free files. The reader does not fulfil ACSM licences, bypass DRM, fetch metadata online, or send reading history to a server. Complex EPUB layouts may not render exactly as in a browser-grade reader.

The standalone Debian package depends on Python 3, Tkinter, Pillow and MPV. Flatpak bundles the appropriate application runtime and audio dependencies.

## Validation

Automated Python 3.12 and Python 3.15 tests, Debian packaging, and both Flatpak integration builds passed on feature commit `ce212d45ab735cfaa3df7d14f504b763d67012a4`. Linux Mint manual testing confirmed saved ebook and audiobook positions survive restart and both Resume actions restore their positions.
